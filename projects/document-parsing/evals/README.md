# Page classification evaluation

This directory holds the offline evaluation for `pdf-page-classifier`: a small
labelled set, a deterministic fixture generator, and a report with metrics,
confusion matrices, and misclassified cases.

The report is [`results.md`](results.md). It is generated, not edited by hand.

## Label rubric

The classifier answers a binary question, so the label needs a rule:

> A page is **diagram** when a figure or schematic is the primary explanatory
> artifact and prose is subordinate. A page is **document** when extractable
> text (prose or table) is the primary artifact.

This matters for the curated pages, which mix both artifacts on every page.
The rubric is recorded in `manifest.json` and repeated at the top of the
generated report.

## Dataset

| Source | Split | document | diagram | Total |
| --- | --- | --- | --- | --- |
| synthetic | calibration | 4 | 4 | 8 |
| synthetic | test | 6 | 6 | 12 |
| curated | test | 3 | 3 | 6 |

- **Synthetic** pages are generated by `make_fixtures.py`. They are not
  committed: the generator is the fixture, so a change in fixture geometry is
  visible in review.
- **Curated** pages are the three self-authored engineering explainers in
  [`fixtures/curated`](fixtures/curated). They are committed because they are
  small and license-clean, and because the report should be reproducible from a
  clean checkout.
- The calibration split contains only synthetic pages. Curated pages are never
  seen during calibration, so the curated metrics measure a real domain gap.
- `assert_disjoint_splits()` fails the run if a case appears in both splits.

### Documented edge and hard cases

| Case | Label | Difficulty | Why it is not a clean case |
| --- | --- | --- | --- |
| `test-scanned-prose` | document | hard | Has no text layer; needs OCR before classification |
| `test-title-page` | document | hard | Only five words, below the word-count threshold |
| `test-blank` | diagram | edge | No artifact at all; the label is unambiguous but the visual branch misreads it |

The report shows metrics with and without the `hard` cases. `edge` cases stay in
the standard table because their label is still well defined.

## Run

```bash
# from the repository root
make eval-doc-parsing

# or directly
python projects/document-parsing/evals/evaluate.py
```

Useful flags:

```bash
--manifest PATH              # alternative manifest
--output PATH                # alternative report path
--gate-model adaptive        # model checked against the failure thresholds
--fail-under-accuracy 0.80
--fail-under-macro-f1 0.80
--skip-missing               # tolerate curated fixtures that are not present
```

The command exits non-zero when a gate fails, so it can be used in CI.

## Reproducibility

- Every generator is deterministic; no random sampling is used for fixtures.
- The bootstrap interval uses a fixed seed (`42`).
- The report contains no timestamps, absolute paths, or machine-specific data.
  Re-running the command on the same commit produces the same file.

## Baseline observations

The first run (before any classifier change) is worth reading closely. The
numbers below are copied from [`results.md`](results.md), which is authoritative:

| Model | Accuracy | Macro F1 | 95% CI |
| --- | --- | --- | --- |
| layout-only | 0.611 | 0.610 | [0.389, 0.833] |
| visual-only | 0.444 | 0.308 | [0.222, 0.667] |
| hybrid | 0.611 | 0.610 | [0.389, 0.833] |
| adaptive | 0.611 | 0.610 | [0.389, 0.833] |

Two findings:

1. **The hybrid never overrides the layout branch.** When the two members
   disagree, the weighted score is always positive, so the hybrid inherits
   every layout decision. It has the same confusion matrix as `layout-only`.
2. **Confidence carries almost no information.** The hybrid emits only two
   values: `0.180` when the members disagree and `0.660` when they agree. The
   curated pages all receive `0.180`.

These are behavioral facts, not a quality claim. The next change should make
scores calibrated and let the evaluation show whether that helps.

## Limitations

- The curated set is designed, not sampled. It does not estimate production
  accuracy.
- N = 18 for the combined test set. The interval is wide, and a single flipped
  page moves accuracy by 5.6 points.
- The synthetic set tests decision mechanics under controlled conditions, not
  visual diversity.
- The binary rubric compresses genuinely mixed pages into one label. That is a
  deliberate product decision, recorded here so the numbers are not over-read.
